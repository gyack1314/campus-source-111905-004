# 来源契约

GET /catalog?version=r1 返回版次、axes、variables与max_cells。不带version返回当前版，阶段0为r1，阶段1以后为r2。版次不可变，r1到阶段2退休后所有读取返回410，r2持续有效。目录轴为物理坐标：time/sample以实验开始后的秒表示，station是测点坐标。各变量dimensions给出维度顺序，禁止按相同数组形状推定对齐。
GET /array.nc?version=r1&variable=temperature&time=0:2&station=1:3 是实际存在的来源读取例子，索引从0开始，区间左闭右开。每个维度可独立选择连续索引范围；省略维度代表全轴，乘积超过max_cells返回413。索引越界返回400，合法空选择返回204，响应版次仍在X-Source-Version。current使用station、sample而非time轴。
成功响应是NetCDF classic，含维度坐标变量、目标变量、同形quality以及source_version属性。原始目标值为int16，_FillValue=-9999，scale_factor/add_offset需与原始字节一同解释；quality=0表示资料存在但不可作为有效观测，quality=1表示来源质控可用。不得把缺测数值乘缩放后当有效值。
r2在time轴中间补2.5秒，station仍为降序，current的非等间距sample轴独立；r2也更新质量掩码。此服务只负责提供原始资料切片，不提供拼接、重采或完成性判断。

演练控制：POST /__control 接收JSON stage及上述控制项，GET /__log显示请求观测；它们供资料源演练与来源测试使用，不属于业务资料获取接口，不得用其直接生成采集结果。每次启动是独立状态。GET /health仅检查服务可用性。
